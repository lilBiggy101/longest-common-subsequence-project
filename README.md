# Longest Common Subsequence (LCS)

## Overview
This project for my CS315 Algorithm Design class had me implement the Longest Common Subsequence algorithm in C++ using dynamic programming to find the longest ordered sequence shared between two DNA strings.

## Concepts
- Dynamic Programming
- 2D arrays and tables
- String comparison
- Sequence reconstruction

## Complexity
- **Time:** O(m × n)
- **Space:** O(m × n)

## How to Run
Compile using g++:

```bash
g++ -g LCS.cpp -o LCS
```

Run the program:

```bash
./LCS
```

## Purpose
Practice implementing dynamic programming and solving problems by breaking them into smaller subproblems.
